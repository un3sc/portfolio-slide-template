# Assets

Coloque seus arquivos de imagem aqui.

## Arquivos esperados

| Arquivo | Descrição | Tamanho sugerido |
|---------|-----------|-----------------|
| `IMG.jpg` | Foto de perfil | 400×400px (quadrada) |
| `favicon.png` | Ícone da aba | 32×32px |
| `github.png` | Ícone GitHub (branco) | 24×24px |
| `linkedin.png` | Ícone LinkedIn (branco) | 24×24px |
| `image.png` | Screenshot do dashboard | 16:9 |

Todos os outros logos e fotos são opcionais e podem ser nomeados como preferir,
desde que os caminhos no `index.html` sejam atualizados.
